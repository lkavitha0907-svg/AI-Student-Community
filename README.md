# AI-Student-Community
Web-based student community with AI quiz generation
## AI Module

This module generates quiz questions automatically from PDF files.

Files included:
- ai.py → Generates quiz questions
- pdf_reader.py → Extracts text from PDF files

Main Function:
generate_quiz_from_pdf(pdf_file)

Workflow:
1. User uploads a PDF
2. Text is extracted from the PDF
3. AI generates quiz questions from the extracted text
4. Questions are sent to the frontend for students
